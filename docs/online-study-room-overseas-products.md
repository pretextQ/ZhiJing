# 海外线上自习室产品拆解

> **已被 [项目基调](../docs/project-charter.md) 作废（2026-11-17）。** 知径已明确为单人自用自习室，不做账号、社交、联机、多人与商业化。本文保留作产品资料留档；其中联机房间、定时照片、虚拟形象、主持人等设计不再适用。以 [单人自习室设计调研](online-study-room-solo-research.md) 为准。

调研时间：2026-11-17。所有结论来自产品官网、官方帮助文档/FAQ、应用商店页与第三方评测，链接见文末。未在官网核实的定价一律标注"未核实"。

> 定位说明：本文拆解的是面向多人的海外自习室产品，其中联机、房间、主持人、排行榜等设计仅作外部参考，不适用于知径。知径是单人自用产品，边界见 [项目基调](project-charter.md)。

## 摘要：海外产品其实在解四道不同的题

| 产品 | 在解的问题 | 形态一句话 |
| --- | --- | --- |
| StudyStream | 随时有人 | 24/7 免预约静音视频宫格 |
| Study Together | 社群归属 | Discord 频道即房间 + 番茄钟 Bot + 时长榜 |
| Focusmate | 强约束 | 1 对 1 预约，互相报到 |
| Flow Club / FLOWN / Caveday | 节奏与仪式 | 有主持人、有脚本的场次 |
| LifeAt | 氛围 | 没有别人，只有环境音和壁纸 |
| Kumospace / Gather / Ohyay | 空间感 | 可走动的 2D 地图 + 邻近音频 |
| gogh / StudyCast / 열품타 | 东亚学生市场 | 虚拟形象 / 房间 + 匹配 / 定时拍照 |

关键洞察：**它们没有一款是"全能自习室"**。每一款只把一件事做到极致，然后靠定价或场景把用户分层。这是最有价值的借鉴——不要做一个"什么都有"的房间。

## 一、StudyStream（英国）——24/7 静音宫格

- **形态**：登录 → 进 focus room → 开摄像头 → 开始工作。摄像头开、麦克风关，几百人同时在线，没有预约、没有主持人、没有时间表。
- **界面**：视频宫格，可 pin 住某个让你有动力的人；自己决定节奏、想待多久待多久。
- **商业化**：免费额度限时，Premium 不限时（具体价格未核实）；Web + iOS。
- **增长路径**：从一个大型学生社区长出来，后来吸收了 Study Together 社区。
- **设计要点**：它把"空房间"问题彻底解决了——**房间数很少、单房很大**，任何时区进来都有人。
- **弱点**（第三方评测明确指出）：大房间的责任感弱于一对一；对陌生人开摄像头不是所有人都能接受；免费限时是主要流失原因。

> 借鉴：如果要做"随时有人"，就别做 20 个小房间，做 1–3 个大房间。

## 二、Study Together（Discord）——频道即房间

- **形态**：一个 24/7 的 Discord 服务器，上百万人。语音/视频频道就是房间，另有共享番茄钟的房间（25/5）。
- **机制**：Bot 记录学习时长、给等级、发排行榜，最高称号 "Study Master"。
- **设计要点**：**零界面成本**——房间列表、成员列表、身份、权限全部复用 Discord；产品只是规则与 Bot。
- **代价**：没有专门的专注界面，用户会看到聊天频道；氛围靠社群管理而非产品约束。

> 借鉴：MVP 阶段完全可以先用现成 IM/语音工具 + 一条 Bot，把"节奏"验证清楚再做原生房间。

## 三、Focusmate——1 对 1 的强约束

- **形态**：预约 → 系统匹配一个人 → 视频开场互报目标 → 各自安静工作 → 结束互相庆祝。
- **参数**：25 / 50 / 75 分钟三档；免费每周 3 次，Plus 约 $8/月（年付，第三方核实）。
- **设计要点**：极简到几乎没有 UI——它卖的是**日程承诺**，不是界面。
- **弱点**（Flow Club 点破）：对方缺席是最常见投诉，一对一太脆弱。

> 借鉴：1v1 适合"高动机、低社交"的用户；但只要产品要规模化，就必须有人数冗余。

## 四、Flow Club（美国）——场次化，9 人上限

已在上一份调研中详述，这里只补产品层面的观察：

- 定位是**"工作方式的健身房"**：预约制、有主持人（host）、有开场报目标与结尾复盘。
- 主持人由**会员志愿担任**，明确不是教练——避免形成监督关系。
- 场次 30 分钟到 3 小时；研究后把 9 人上限在 30 分钟场次下调到 5 人。
- 为非母语/低社交能量用户提供 **chat-only（纯文字）场次**。
- 定价 $40/月，学生与非营利五折。社区调研称 62% 会员自述有 ADHD。

## 五、FLOWN（英国）——把"格式"做成产品目录

FLOWN 是目前把"自习室的不同使用场景"拆得最细的产品，值得整段抄它的信息架构：

| 格式 | 说明 | 类比（官方原话） |
| --- | --- | --- |
| Drop-In | 24/7 静音房，自定节奏，无主持、不说话；侧栏写目标、自带番茄钟、可分享歌单 | 虚拟图书馆 |
| Focus Sessions | 有主持人、有开场与收尾、1–2 小时结构化场次 | "把事做完的健身课" |
| Peer-to-Peer | 更小的主题场次（练琴、找工作、断舍离），会员可自己开 | DIY 互助小组 |
| Focus Rooms | 私密房间，链接分享给朋友/同事 | 和朋友一起 body double |
| Take-Off | 20 分钟晨间仪式：轻运动 + 日记 + 周计划 + 报目标 | 晨会 |
| Recharge / Airflow | 呼吸、冥想、时间块、拉伸 | 恢复 |

- 每周 **350+ 场**，主持人 20+ 位（多为教练、写作者、正念老师）。
- 关键：**自建原生视频**（不依赖 Zoom），内置番茄钟、意图设置、聊天、音乐、虚拟背景、画中画。
- 游戏化：streaks、徽章、社区挑战、兑换券。
- 说明：它把"陪伴"从一个房间扩展成了一张**日程表**——用户订阅的是"总有一场马上开始"。

> 借鉴：知径如果做联机，可以把"格式"作为一等公民：静音房 / 番茄场 / 讨论场，各有自己的默认参数与 UI，而不是一个房间塞所有开关。

## 六、Caveday（美国）——Zoom 上的"主持人驱动"

- **形态**：预约 Cave → 邮件收到 Zoom 链接 → 到点进会。
- **脚本**：主持人欢迎 → 先在小分组里说今天要做什么（说多说少随意）→ 再回大组每个人过一遍目标 → 深度工作冲刺 + 提神休息交替 → 结尾分享战果。
- **参数**：30 分钟 / 1 小时 / 3 小时；7 天全周，每天 20+ 小时有场次；**开场 10 分钟后关门，迟到者不得入内**。
- **摄像头**：鼓励开，但**全员静音**——所以你可以做会出声的事（打电话、打碟、做家务）。
- **主持人叫 Cave Guide**，官方比喻是"像瑜伽馆里不同风格的老师"。
- **提前离开**：给主持人私信 + 分享一个小成果即可。

> 借鉴：**10 分钟锁场**是很好的设计——它让"准时"成为房间规则的一部分，也让场次的仪式感成立。

## 七、LifeAt——氛围优先，没有别人

- 定位不是"和别人一起学"，而是"把你的桌面变成一个沉浸空间"：动态壁纸（自然景观/室内）、专注音乐、秒表、番茄钟、笔记、待办、日历、虚拟 co-working。
- 官方宣称依据 **注意力恢复理论（ART）**，并称被 ADHD 专业人士采用；官网标称 1000 万+ 用户。
- 用户评价里最常出现的场景是**放在第二块屏幕上**（"lifeat.io 放副屏"）。
- 设计要点：**"陪伴感"可以完全不来自人**——环境音 + 场景 + 计时器就能成立。

> 借鉴：这条对知径最重要。你的六款场景 + 环境音 + 计时器已经是同一套逻辑，且不依赖网络与他人。

## 八、Kumospace / Gather / Ohyay——空间型

- **Kumospace**：可编辑的 2D 平面图，摆家具、划房间。**房间本质是"私有音频区"**：进了房间，无论彼此多远都能互相听见；房间外则是随距离衰减的空间音频。房间可以有门，从外面点门就是"敲门"。
- **Gather**：2D 地图 + 虚拟形象，靠近才连视频；private area 用来关掉邻近音频。
- **Ohyay**：可把视频"摆"在座位上的房间式布局，香港城大的那篇论文正是用它做实验（Gallery vs Room）。

> 借鉴：**音频分区比座位像素更重要**。如果只能做一件事，做"进房间即静音/讨论区独立音轨"，不要做家具。

## 九、东亚三款：gogh、StudyCast、열품타

### gogh（日本，Steam）
- 虚拟形象捏脸 + 房间布置 + 番茄钟 + 待办 + 笔记 + 宠物；**多人房间上限 16 人**。
- **联机时没有聊天，只能发表情和动作**；番茄钟结束后可以在房间里玩小游戏。
- 定价约 ¥45 买断，后续靠 DLC（场景/装饰/音乐/形象）。
- 用户反馈：房间自定义操作手感差；被"个性化"吸引进来的人最多。

### StudyCast / スタキャス（日本，Benesse）
- 面向中高中生：**在线自习室 + 学习计时器 + 学习匹配（1 对 1 比学时长）+ AI 拍照答疑（7 科）+ 学习报告 + 图书库**。
- 社交信号用"印章"互勉；有"公认用户徽章"。
- 规模：突破 200 万下载；官方调查（370 名周活 3 次以上用户）称"干劲提升"。
- 设计要点：**自习室只是获客入口，真正留存靠学习管理与答疑**。

### 열품타（韩国，Yeolpumta）
- 核心是"纯学习时间（순공시간）"秒表 + 按科目自动生成学习计划表 + 小组。
- **cam study 不是实时视频，而是每 20–30 秒拍一张照片**：组员看到的是"你刚才在学的照片"和"摄像头在线时长"；关屏或使用允许的应用时不拍照；可以完全不授权摄像头（显示为图标）。
- 由第三方（CLUB STUDY FOCUS）延伸出的"高强制"变体：约好时间进 Zoom 自习室，5 分钟后每 5 分钟确认电话，20 分钟仍未到罚 3,000 韩元。

> 借鉴：**定时照片**是隐私与带宽的最优解之一——比直播便宜、比纯计时可信，而且天然规避了"被别人盯着看"的不适。这是国内产品几乎没做过的一档。

| 是否需预约 | 否 | 否 | 是 | 是 | 部分 | 是 | 否 | 否 | 否 | 否 | 否 |

| 视频 | 直播宫格 | 直播 | 直播 | 直播 | 直播 | 直播(Zoom) | 无 | 直播/头像 | 虚拟形象 | 直播/照片 | **定时照片** |
| 主持人 | 无 | 无 | 无 | 会员志愿 | 专业主持 | Cave Guide | 无 | 无 | 无 | 无 | 无 |
| 节奏载体 | 无 | 番茄 Bot | 固定时长 | 场次脚本 | 场次+格式 | 场次脚本 | 自定计时 | 无 | 番茄钟 | 计时/匹配 | 秒表 |
| 商业化 | 免费限时+订阅 | 免费 | 免费额度+订阅 | $40/月 | 会员制 | 会员制 | 免费+Pro | 免费+付费 | 买断+DLC | 免费+合作 | 免费+广告 |

三条规律：

1. **免费的那几款都用"随时有人"做钩子，收费用"节奏与主持"做理由。**
2. **人数和约束强度成反比**：1v1 最强但最脆；9 人适中；几百人只提供氛围。
3. **越往东亚走，产品越"管理化"**（时长、照片、报告、匹配），越往欧美走越"仪式化"（主持人、开场、庆祝）。

## 十一、可以拿去用的 12 个具体设计

1. **格式即参数**（FLOWN）：静音房 / 番茄场 / 讨论场是三种预设，不是一个房间塞满开关。
2. **房间少而大**（StudyStream）：避免空房间；宁可千人一厅，不做二十个空房。
3. **10 分钟锁场**（Caveday）：迟到不得入内，准时成为规则。
4. **主持人不是教练**（Flow Club）：同伴轮值，避免监督关系。
5. **30 分钟场次 ≤5 人**（Flow Club）：短场次里自我介绍会吃掉专注时间。
6. **定时照片**（열품타）：隐私友好、带宽友好、依然可信。
7. **私密房间靠链接**（FLOWN）：最多两人/几人，熟人社交的最低成本形态。
8. **房间 = 私有音频区**（Kumospace）：静音/讨论用音轨隔离，不用像素隔离。
9. **敲门与关门**（Kumospace）：陌生人准入是一个可交互的物件，而不是一个设置项。
10. **氛围可以没有别人**（LifeAt）：场景 + 声音 + 计时器本身就是产品。
11. **副屏意识**（LifeAt）：自习室常常是被"放在旁边"的，UI 应为旁观而非主视设计。
12. **自习室只是漏斗口**（StudyCast）：真正的留存来自学习记录、复盘与答疑。

## 十二、对知径的三条结论

1. **不要做直播宫格**。你最强的资产是"场景 + 环境音 + 计时器"的沉浸感（lifeAt 已证明这条路能到千万级用户），而直播宫格会把你拖进带宽、合规、隐私与运营的深水区，且与"安静、克制"的产品调性冲突。
2. **如果一定要联机，先做"照片式在场"**：定时快照 + 状态点 + 一句目标。成本极低、隐私风险小、可异步，且国内几乎无人这么做过。
3. **把"格式"做成产品差异点**：静音房（默认）/ 番茄场（共享计时）/ 讨论场（音频分区）。三者复用同一套场景与主题包，只在默认参数与 UI 上分化。
