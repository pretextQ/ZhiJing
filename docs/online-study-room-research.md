# 线上自习室布局与设计调研

> **已被 [项目基调](../docs/project-charter.md) 作废（2026-11-17）。** 知径已明确为单人自用自习室，不做账号、社交、联机、多人与商业化。本文保留作资料留档，其中关于联机房间、虚拟座位、主持人、陪伴社交的设计建议不再适用。以 [单人自习室设计调研](online-study-room-solo-research.md) 为准。

调研时间：2026-11-17。资料来源为公开产品页、官方 FAQ/Blog、行业分析与一篇 HCI 论文，链接见文末。

> 定位说明：本文调研的是“多人线上自习室”品类，其中影子房间、联机小房间、摄像头、主持人等建议仅作外部参考，不适用于知径。知径是单人自用产品，边界见 [项目基调](project-charter.md)。

## 摘要

1. **线上自习室卖的不是"房间"，是 body doubling（同伴在场效应）**：看见别人在做事，比被监督更能促发专注。所有设计都应服务于"低压力地被看见"，而不是"被管理"。
2. **两层结构是几乎所有成功产品的共识**：大厅/广场解决"随时有人"，小房间解决"具体的这一段专注"。两层不要混成一个。
3. **人数不是越多越好**：Flow Club 用 40 万场会话得出 9 人上限（30 分钟场次降到 5 人）；gogh 为 16 人；大型广场是几百人。小房间的关键是"不被点名、也不消失"。
4. **视频宫格（Gallery）与虚拟座位（Room）是两种空间隐喻，取舍明确**：香港城大研究显示 Room 布局提升群体注意力与团队感，但也放大自我意识，用户会"躲开聚光灯"。做静音自习用宫格更稳，做讨论/破冰用座位更有效。
5. **分区靠"音频隔离"而不是靠"距离"**：静音区、讨论区、休息区必须音频独立，切换分区是给大脑的模式切换信号。
6. **节奏即产品**：开场报目标 → 专注块 → 同步休息 → 收尾复盘，这套脚本比任何界面元素都更能提升完成率。
7. **摄像头必须可选**，并且要给"只看不露"的中间态（仅手部/桌面、虚拟形象、模糊）。
8. **控制条、计时器、场景背景三层分离**，UI 不得侵入视频区中心；计时器是唯一的常驻强信息。
9. **反模式很集中**：社交/换装/游戏膨胀、陌生人闯入、把免费房间缩到 3–4 人做付费墙、排行榜羞辱。国内媒体已对这类"变味"点名批评。
10. **对知径**：现有单人场景 + 主题包 + 环境音已经是最好的"房间底座"，联机应从"异步在场感"起步，而不是直接做视频宫格。

## 一、机制：为什么线上自习室有效

| 机制 | 说明 | 设计含义 |
| --- | --- | --- |
| Body doubling | 旁边有人在做同样的事，启动阻力下降 | 在场信号必须"可见但不需要互动" |
| 公开承诺 | 开场说出今天要做什么，目标被外部化 | 需要一个低摩擦的目标输入口 |
| 时间盒 | 25/50/90 分钟的时间边界降低启动成本 | 共享计时器是房间的主时钟 |
| 仪式与归属 | 固定时间、固定房间、固定的人 | 房间要有"老地方"感（命名、常客、固定场次） |
| 轻社交 | 休息时的三分钟闲聊，不是社交广场 | 社交必须"发生在休息区"，不进入专注区 |

Flow Club 在 40 万场会话后给出的结论很直接：一对一太脆弱（对方缺席就崩），大房间太稀释（"我觉得自己隐形了"），小群体才稳定。

## 二、形态谱系：四种房间，四套布局

| 形态 | 容量 | 音视频 | 适合人群 | 布局要点 |
| --- | --- | --- | --- | --- |
| 图书馆式静音室 | 9–300 | 摄像头开、麦克风关 | 考研/公考/CPA 长周期 | 视频宫格 + 全场静音 + 极简 UI；不需要控制条以外的任何东西 |
| 番茄钟自习室 | 5–30 | 摄像头可选、麦克风按节奏开 | 职场技能、周末打卡 | 共享计时器为主角，房间状态随计时器变化（专注/休息） |
| 小组连麦讨论室 | 5–17 | 双向音视频 | 留学、论文、资格互助 | 需要"发言位"概念、举手、发言高亮；人数超过 17 连麦体验崩塌 |
| 自习广场 | 数百–数千 | 主播式、单向 | 机构流量池、会员权益 | 巡场老师、弹幕/鼓励、榜单；个人不存在感强，靠运营而非界面 |

关键判断：**一个产品不要同时把四种都做了**。主流做法是"广场做拉新、小房间做留存"，且两者的 UI 完全不同。

代表产品对照：

- **StudyStream / CSW**：24/7、免预约、摄像头开麦关、几百人同房，强调"为内向者设计：在场但不出镜"。
- **Study Together（Discord）**：频道即房间，番茄钟 Bot + 学习时长排行榜。
- **Flow Club**：预约制、≤9 人、有同伴主持人（host），30–180 分钟，开场报目标、结尾庆祝；另有纯文字（chat-only）场次照顾低社交能量用户。
- **Focusmate**：1 对 1，25/50/75 分钟，免费额度 + 订阅。
- **gogh**：游戏化虚拟形象、房间公开、≤16 人、无聊天只有表情动作、番茄钟后可在房间里玩小游戏。
- **CoStudy**：虚拟校园/教学楼/教室选座，座位可点开看目标与专注状态，隐私可关。
- **flat.social**：可自由走动的空间音频房间，静音区与讨论区靠音频隔离区分。

## 三、空间布局（虚拟场地）

### 3.1 两层结构

```
大厅 Lobby        → 一句"现在有 128 人在学" + 房间列表（按目标/科目/语言/人数）
  └ 小房间 Room   → 9 人以内、有主题、有节奏、有主持人
  └ 广场 Plaza    → 只读氛围、可选"我也在学"
```

大厅要回答一个问题：**"我现在去哪一间？"** 因此房间卡片至少包含：主题名、当前人数/容量、节奏（25/5 或 50/10）、是否静音、语言、正在学的方向。

### 3.2 分区与音频隔离

- **静音区**：默认全静音，只能发文字/表情。任何"接近真实图书馆"的体验都靠这里。
- **讨论区**：独立音频通道，不进静音区。人数上限 5–9，超过需要拆桌。
- **休息区**：番茄钟休息时全房间"搬"过去的同一个空间（或同一套背景），是社交发生的唯一合法场所。
- **白板/便签区**：写本次目标，公开承诺的载体。
- **门口（候场）**：进房前的 3 秒预览——摄像头预览、房间规则、静音提醒。

设计原则：**分区的边界是声音，不是画面**。画面可以共享，音频必须物理隔断；用户在静音区能"看见"讨论区在聊，但一个字都听不到，这正是空间感的来源。

### 3.3 座位隐喻 vs 视频宫格

一项针对 2D 视频通话空间布局的研究（City University of Hong Kong，以 Ohyay 为平台）对比了 Gallery（等大宫格）与 Room（视频"坐"在教室座位上）：

- Room 布局下，参与者把注意力更多分配给群体，并且**自我意识显著增强**；讨论任务中团队归属感更强。
- 参与者明显出现"**躲开聚光灯**"的行为（缩小/后移/边缘化自己），也会利用空间方位表达立场（靠近=共情，远离=对立）。
- 结论：空间布置应按任务选择——社会支持型任务更适合圆桌式，对立讨论更适合分列式。

落地建议：**静音自习用宫格（降低自我意识），小组讨论/破冰用座位（提升团队感）**；两者不要在同一界面混用。虚拟座位图的额外成本是"选座"这一步的摩擦，CoStudy 用"教学楼—教室—座位"三层结构换取代入感，代价是新用户要学一套空间规则。

### 3.4 容量与密度

- 小房间 **6–9 人**：大到不被点名，小到不隐形。
- **30 分钟场次 → 5 人**；短场次里自我介绍会吃掉专注时间。
- 超过 12 人：需要"分身/分桌"，否则出现"跳过某人"的挫败感。
- 广场：几百人以上，个人只作为"氛围像素"存在，必须有运营角色巡场。
- 房间空置是最伤的体验：宁可把新人导进"当前人最多"的房间，也不要给一个空房间。

### 3.5 动线与准入

- 进入 ≤2 步：点房间 → 预览（摄像头/规则）→ 进。
- 迟到者走"静默入场"：不打断、只在目标板补一行；早退者在离开前留一句进度。
- 陌生人进入：房间要有"敲门/主持人确认"或"仅链接可见"的开关；国内用户对陌生人闯入的投诉非常集中。

## 四、界面布局（屏幕排布）

### 4.1 视频区

- 卡片比例固定 1:1 或 4:3（人脸为主），不要 16:9——宽画幅会让书本和桌面上半部被裁掉。
- 宫格自适应：1 人 = 单卡居中；2–4 人 = 2 列；5–9 人 = 3 列；超过 9 人转入"拼贴墙 + 滚动"。
- **自己不在第一格**：自己的画面放右下角小窗，或固定末位，避免"对着自己学习"。
- 空位显示为"空座"而不是让格子弹跳重排——重排会不断夺走注意力。
- 视频小卡上的信息只保留：昵称（可隐藏）、状态点（专注/休息/离开）、是否静音。**不要放目标全文**，目标在侧栏。

### 4.2 三层信息架构

```
背景层：场景/主题（雨窗、图书馆…）+ 极轻动效
主体层：视频宫格 / 虚拟座位 / 白板
控制层：计时器（常驻且唯一强信息）、目标、声音、成员、退出
```

- 计时器放在视觉重心偏移处（顶部居中或右下），不压在任何人脸中心。
- 控制条默认半透明，鼠标静止 3 秒后淡出，仅保留计时器与"退出"。
- 侧栏（成员/目标/白板）可折叠，不挤压视频区；窄屏时变成底部抽屉而不是覆盖层。

### 4.3 在场信号

- 状态三态：**专注中 / 休息中 / 暂时离开**，由计时器自动驱动，不靠用户手动切换。
- 轻反应：完成一个番茄钟可发一次表情（鼓掌、火苗），无弹幕、无连续刷屏。
- 环境音：翻书、打字、雨声、lofi——声音比画面更能"证明有人在"（《放松时光》用 100+ 种拟音做陪伴感）。
- 排行榜要谨慎：它制造比较压力，且对考公/考研长周期用户是负向的；若要留，默认折叠并只展示"自己的本周时长"。

### 4.4 摄像头与隐私

- 默认关闭，进房时给三个等价选项：**开摄像头 / 仅露桌面或手部 / 只看不露**。
- "仅手部"是被低估的中间态：既保留"有人在学"的证明，又完全不暴露面部。
- 提供虚拟形象/像素替身兜底（gogh、CoStudy 的做法），给不拍照的人群一个出口。
- 明确告知：不录屏、不截图由应用保证；应用自身不保存画面。

### 4.5 窄屏与无障碍

- 320–480px：单人 / 双人竖排，宫格改 2 列，计时器置顶固定，控制条沉底。
- 全部操作可键盘完成；焦点顺序：房间列表 → 视频区 → 参与者 → 计时器 → 退出。
- 支持"减少动效"：背景动效、卡片入场、反应动画全部降级为静态。
- 对比度：文字与背景 ≥ 4.5:1；不要在浅色场景图上直接压白字，加一层 12–20% 的暗色渐变遮罩。

### 4.6 视觉基调

线下自习室的设计可迁移：暖木色 + 低饱和绿（安静感）、雾面材质防眩光、均匀照明不刺眼、座位避免正对/背对窗户。数字对应物就是：**低饱和背景、无高频动效、无纯白大面积、无高对比红黄**。状态色克制使用——红只用于"即将结束"，绿只用于"完成"。

## 五、时间布局（节奏）

一场 50 分钟的标准脚本：

| 时间 | 环节 | 界面 | 目的 |
| --- | --- | --- | --- |
| 0–3 分 | 报目标 | 目标板输入一行，其他人可见 | 公开承诺 |
| 3–48 分 | 专注块 | 全静音、宫格、计时器倒计时 | 深度工作 |
| 48–55 分 | 同步休息 | 背景切换、聊天区解锁、可发反应 | 模式切换 |
| 55–60 分 | 收尾 | "今天的进度"一句话 | 正反馈与留痕 |

- 时长档位：25/5、50/10、90/15。规则不要超过三档。
- **主持人（host）机制**：由常客轮值，负责开场、控时、收尾。Flow Club 明确"主持人不是教练"，避免出现监督关系——一旦有"老师看着你"的感觉，body doubling 就退化为被监视。
- 迟到/早退是常态：不要因为一个人缺席而让整场节奏变化（这正是小群体优于 1v1 的原因）。
- 休息必须被"强制"：这是产品对用户的承诺，也是降低"刷手机"的机制。

## 六、反模式清单

1. **社交膨胀**：换装、交友、广场八卦压过学习本身。国内已有多篇媒体调查点名"线上自习室变味"。
2. **陌生人随意闯入**，且在静音区开麦。
3. **付费墙把免费房间压缩到 3–4 人**：免费房间被秒抢，用户体感是"处处受限"。
4. **强制开摄像头**，或以"不开摄像头就没有陪伴感"施加道德压力。
5. **排行榜羞辱**：把学习时长做成排名，对进度落后的备考者是二次打击。
6. **空格子 + 频繁重排**：每来一个人，所有人的画面都跳动一次。
7. **把计时器做成全屏遮罩**：用户想边看视频课边专注时无处可放。
8. **功能堆叠**：白板、共享文档、AI 助手全塞进房间，专注区变成会议室。

## 七、可直接落地的设计规范（建议值）

| 项 | 建议值 | 依据 |
| --- | --- | --- |
| 小房间容量 | 6（默认）/ 9（上限） | Flow Club 9 人上限、30 分钟场次降至 5 |
| 短场次容量 | 5 | 同上 |
| 视频卡比例 | 1:1 | 桌面/书本的取景需要 |
| 宫格列数 | ≤4 人 2 列，5–9 人 3 列 | 常见视频会议与自习产品实践 |
| 自己的位置 | 右下角小窗（可拖拽） | 避免自我注视 |
| 控制条自动隐藏 | 静止 3s 后淡出 | 降低视觉噪音 |
| 计时器字号 | ≥ 屏幕短边 8% | 余光可读，无需聚焦 |
| 音视频延迟目标 | < 300 ms | 连麦讨论可用的技术门槛 |
| 弱网指标 | 抗丢包 > 80% | 宿舍/移动网络环境 |
| 默认麦克风 | 关闭 | 静音是默认态，开麦是显式动作 |
| 默认摄像头 | 关闭（三选一入口） | 隐私与内向者友好 |
| 动效时长 | ≤ 200 ms，可全局关闭 | 减少动效偏好 |
| 房间卡片信息 | 主题、人数/容量、节奏、静音、方向 | 大厅决策所需最小集 |

## 八、对知径的落地建议

知径当前是一个**单人本地自习室**（六款场景、专注与休息计时、目标、待办、统计、本地歌单与环境音、看课笔记）。这个底子恰好是"房间"的雏形：场景 = 空间，环境音 = 声音，计时器 = 节奏。

建议分四步，每步都能独立发布：

**阶段 0（打磨现有单人体验）**
- 把"专注块 → 休息"的节奏做成显式的三段式状态，而不是隐式计时。
- 环境音与场景解耦程度再提高一点：同一场景下可选"雨/图书馆/咖啡馆"。

**阶段 1（异步在场感，不联机）**
- "影子房间"：展示同一场景下此刻有多少人在学（只读、匿名），提供"我也在学"的氛围。
- 学习时长只对本人可见，不做公开排行榜。
- 成本极低，能验证"陪伴感"是否真的带来留存。

**阶段 2（小房间联机，≤6 人）**
- 只做图书馆式静音室：摄像头可选、麦克风默认关、文字/表情为唯一互动。
- 复用现有主题包作为房间背景，房间 = 主题 + 节奏 + 人数上限。
- 入场预览页：3 秒摄像头预览 + 房间规则一句话。
- 不引入虚拟形象与座位选座（与知径"安静、克制"的调性冲突）。

**阶段 3（节奏与主持）**
- 共享番茄钟、目标板、同步休息。
- 常客轮值主持人（同伴制，不做"老师"角色）。
- 房间准入：链接可见 / 密码 / 公开三档。

**与笔记的衔接**：看课笔记是知径的差异点，联机时可以让房间共享"当前课程"，但不共享笔记正文——只共享"我在看第 3 讲"，把隐私边界划在内容之外。

## 九、可度量的验收指标

- **房间进入成功率**：从大厅点击到真正开始计时 ≥ 80%。
- **首场完成率**：进入后完成至少一个完整专注块 ≥ 60%。
- **7 日回访**：同一房间/同一时段回访 ≥ 35%。
- **摄像头开启率**：不必追求高，40–60% 属健康；强制拉高会伤害留存。
- **空房间率**：任何时刻空房间占比 ≤ 20%，超出说明房间数过多或入口引导有问题。
- **退出原因**：把"被注视不舒服""有人开麦""人太多/太少"作为一等监控项。
